# High-Level Programming

**Holberton School · Software Engineering Coursework**

A broad collection of programming exercises in Python, JavaScript, SQL and web application development.

## Technology and concepts

Python, JavaScript, SQL, HTML, Flask, REST APIs and automated tests.

## Modules

| Directory | Focus |
| --- | --- |
| [`html_advanced/`](./html_advanced/) | Semantic HTML structures, page sections and style guide markup. |
| [`javascript-dom_manipulation/`](./javascript-dom_manipulation/) | Browser DOM selection, manipulation, events and network interactions. |
| [`javascript-warm_up/`](./javascript-warm_up/) | Introductory JavaScript logic, loops, objects and functions. |
| [`python-classes/`](./python-classes/) | Python class design, data encapsulation and object behavior. |
| [`python-data_structures/`](./python-data_structures/) | Lists, tuples, element manipulation and iteration. |
| [`python-exceptions/`](./python-exceptions/) | Defensive programming with Python exception handling. |
| [`python-hello_world/`](./python-hello_world/) | Python syntax, strings and formatted output. |
| [`python-if_else_loops_functions/`](./python-if_else_loops_functions/) | Python branching, loops and reusable functions. |
| [`python-import_modules/`](./python-import_modules/) | Python modules, imports and command-line arguments. |
| [`python-inheritance/`](./python-inheritance/) | Class relationships, type checking and inherited behavior. |
| [`python-input_output/`](./python-input_output/) | File operations, JSON serialization and object representation. |
| [`python-more_classes/`](./python-more_classes/) | Expanded object-oriented Python examples using rectangle models. |
| [`python-more_data_structures/`](./python-more_data_structures/) | Dictionaries, sets, list comprehensions and collection operations. |
| [`python-object_relational_mapping/`](./python-object_relational_mapping/) | MySQL queries and object-relational mapping concepts. |
| [`python-serialization/`](./python-serialization/) | Serialization formats, including JSON, pickle, CSV and XML. |
| [`python-server_side_rendering/`](./python-server_side_rendering/) | Flask server-side rendering, Jinja templates and data-driven pages. |
| [`python-test_driven_development/`](./python-test_driven_development/) | Python functions and test-driven validation with test fixtures. |
| [`restful-api/`](./restful-api/) | HTTP clients, standard-library HTTP services, Flask APIs and basic security. |
| [`SQL_introduction/`](./SQL_introduction/) | Fundamental SQL queries, databases, tables and records. |
| [`SQL_more_queries/`](./SQL_more_queries/) | SQL permissions, data constraints, relational queries and joins. |

## Working with the exercises

Review the individual directory README files and exercise source before running or compiling them. Each task may have its own dependencies, test driver, or required inputs; do not assume every file is a standalone program.
